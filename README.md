# Ana Mota · Business AI
Sistema Operacional de Marketing Pessoal

## Como publicar (GitHub + Vercel)

### Passo 1 — Criar repositório no GitHub
1. Acesse github.com e faça login
2. Clique em **"New repository"**
3. Nome: `ana-mota-business-ai`
4. Deixe como **Public**
5. Clique em **"Create repository"**

### Passo 2 — Enviar os arquivos
No repositório criado, clique em **"uploading an existing file"** e envie:
- `package.json`
- `vite.config.js`
- `index.html`
- A pasta `src/` com os arquivos `main.jsx` e `App.jsx`

### Passo 3 — Conectar ao Vercel
1. Acesse vercel.com e faça login com o GitHub
2. Clique em **"Add New Project"**
3. Selecione o repositório `ana-mota-business-ai`
4. Framework: **Vite** (será detectado automaticamente)
5. Clique em **"Deploy"**

Pronto — em 2 minutos o app estará no ar com um link público.
